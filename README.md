# Imperium
A system for building a self-sustaining family economy.

## Getting Started

### Prerequisites
- Node.js
- npm
- PostgreSQL

### Installation
```bash
git clone https://github.com/0m0D1NGR0NALD/Imperium.git
cd Imperium
npm install
```

### Running the Backend
```bash
cd backend
npm run dev
```

### Running the Web App
```bash
cd web
npm run dev
```

### Running the Mobile App
```bash
cd mobile
npm run dev
```
