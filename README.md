# Imperium
A system for building a self-sustaining family economy.

## Getting Started

### Prerequisites
- Node.js 18+
- npm 9+
- PostgreSQL (for backend)

### Installation
```bash
git clone https://github.com/0m0D1NGR0NALD/Imperium.git
cd Imperium
npm install
```

### Running the Backend
```bash
npm run dev:backend
```

### Running the Web App
```bash
npm run dev:web
```

##### Install Dependencies
```bash
npm install axios react-router-dom
```

### Running the Mobile App
```bash
npm run dev:mobile
```
